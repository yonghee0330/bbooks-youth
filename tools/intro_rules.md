# 청소년 책 소개 작성 규칙 (비북스 · 청소년 책사줄게)

카카오 책 검색 원문(`introKakao`)은 참고만 한다. 그대로 옮기지 않는다.

## 목적
청소년이 표지를 눌렀을 때, **이 책을 고를지 말지** 바로 판단할 수 있게 돕는다.

## 형식
- 해요체. 짧고 리듬 있게.
- **2~4문장**, 전체 **90~170자**(공백 포함). 절대 중간에 끊기지 않게.
- 첫 문장: 이야기의 상황·주인공·질문을 훅으로.
- 다음 문장: 읽으면 어떤 기분·생각·재미가 오는지.
- (선택) 마지막: “이런 친구에게 잘 맞아요” 한 줄.

## 해도 되는 것
- 스포일러 없는 줄거리 맛보기
- 청소년이 공감할 감정·학교·친구·가족·진로·사회 이슈 연결
- 쉬운 말. 어려운 개념은 풀어서.

## 하지 말 것
- 출간·절판·재출간·판매 부수·베스트셀러·개정판·마케팅 문구
- “본 도서는…”, “출간되었다”, “필독서로 자리매김”
- 문장 중간에서 잘린 듯한 끝, 말줄임표로 때우기
- 지은이·출판사 홍보체, 과도한 찬사(“명작”, “걸작”)만 나열
- 카카오 소개를 문장만 살짝 고친 패러프레이즈

## 출력
책마다 소개 본문만. 제목·따옴표·머리말 없이 순수 소개 문장.
